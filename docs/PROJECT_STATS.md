## Module Overview

### Technical Modules (Require Programming)

1. **Swarm Engine** (`backend/swarm/`)
   - Focus: Multi-agent orchestration, parallel LLM calls
   - *Open for AI/ML contributors*

2. **Digital Twin** (`backend/digital_twin/`)
   - Focus: Teacher persona modeling, Vector RAG
   - *Open for Data Science contributors*

3. **Hybrid Infrastructure** (`backend/infra/`)
   - Focus: Cloud/Local routing, failover, scaling
   - *Open for Cloud/DevOps contributors*

4. **Consensus Configuration** (`config/`)
   - Focus: Voting weights, veto logic, scoring algorithms
   - *Open for Cloud/DevOps contributors*

### Business Modules (No Programming Required)

5. **Marketing & Business Strategy** (`docs/`)
   - Focus: Market research, pricing, investor pitch, financial projections
   - *Tools: Word, Excel, PowerPoint - no coding!*
   - *Open for Business/Marketing contributors*
